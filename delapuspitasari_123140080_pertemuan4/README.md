## Deskripsi Singkat Program

### 1. Program Penghitung BMI (`tugas1_bmi.py`)
Menerima input berat badan (kg) dan tinggi badan (m), menghitung nilai BMI ($BMI = \frac{\text{berat}}{\text{tinggi}^2}$), serta menentukan kategori status berat badan (`Berat badan kurang`, `Berat badan normal`, `Berat badan berlebih`, atau `Obesitas`).

### 2. Pengelolaan Data Nilai Mahasiswa (`tugas2_nilai_mahasiswa.py`)
Mengelola list berisi 5 dictionary data mahasiswa. Mengkalkulasi Nilai Akhir (30% UTS + 40% UAS + 30% Tugas), memetakan Grade (A - E), menampilkan tabel rekapitulasi teratur, serta menentukan nilai tertinggi dan terendah.

### 3. Modul Matematika Python (`math_operations.py` & `main.py`)
- `math_operations.py`: Modul kustom berisi konstanta `PI`, fungsi kalkulasi geometri (persegi, persegi panjang, lingkaran), serta fungsi konversi suhu (Celsius ke Fahrenheit dan Kelvin).
- `main.py`: Skrip utama untuk menguji seluruh fungsi modul dengan dua cara impor (`import math_operations as mo` dan `from math_operations import ...`).
